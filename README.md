# Dignified-Hearing-Companion-Prototype

A premium, accessible, responsive React/Vite interactive prototype for the **Dignified Hearing Aid & Audio Companion** interface based on the Stitch design system.

## 🌟 Overview

**Dignified** is a companion web application designed for smart hearing devices and soundscape management. It prioritizes clarity, calm aesthetics, accessible contrast, and tactile interaction.

### 🎨 Design System:
- **Primary Color**: Slate Blue (`#324a5f`) & Slate Container (`#4a6278`)
- **Typography**: *Plus Jakarta Sans* (headlines) & *Atkinson Hyperlegible Next* (body)
- **Icons**: Material Symbols Outlined & Lucide Icons
- **Accessibility**: High Contrast Mode toggle & Text Size Scaling (100% - 130%)

---

## 📱 8 Key Screens

1. **Home Dashboard**: Master volume slider (0-100), Left & Right hearing aid battery levels, active listening mode indicator, and quick soundscapes.
2. **Hearing Controls**: Fine-tuning for Left/Right ear balance, Speech Clarity boost, Background Noise Reduction level, and a "Reset to Default" action.
3. **Listening Modes**: Interactive mode catalog (*Conversation*, *Quiet*, *Outdoor*, *Music*) and a 4-band equalizer *Custom Profile* modal.
4. **Soundscapes & Tinnitus Relief**: Ambient audio player (*Rain*, *Nature*, *Focus*, *Café*, *Calm*) with intensity slider and play/pause controls.
5. **Environment & Smart Suggestions**: AI ambient noise scanner with animated sound waves, decibel gauge (72 dB), and one-tap suggestion application.
6. **Listening Insights**: 7-day wear time bar chart (12.4 hrs/day avg), top environment usage, and projected battery runtime metrics.
7. **Profile & Accessibility**: Member account info, paired device status, font scaler, high-contrast toggle, and notification preferences.
8. **Welcome & Setup**: Onboarding screen with animated sound wave graphics and interactive device connection simulation.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or Node.js 20+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/varun051206/Dignified-Hearing-Companion-Prototype.git

# Navigate into project directory
cd Dignified-Hearing-Companion-Prototype

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🛠️ Build

To generate the production bundle:

```bash
npm run build
```
